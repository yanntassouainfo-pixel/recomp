## 3. Différenciation réelle vs retard

**Différenciant** : KPI composite à la place du poids (tous les leaders sont poids-centrés) ; nutrition + entraînement + revue dans un seul moteur (MacroFactor et RP vendent deux apps) ; l'inertie justifiée (« ne rien changer ») que personne ne théorise ; Evidence Layer par conseil ; Life Mode / Ramadan, demande réelle servie par personne ; Afrique de l'Ouest (seul AfriCal, nutrition seule).

**En retard** : base alimentaire et logging (photo-reconnaissance chez MFP, Yazio, Foodvisor, MacroFactor) ; pas de prix, pas de store, zéro preuve sociale ; preuve algorithmique (MacroFactor : 13 000 avis à 4,8) ; intégrations wearables absentes.

## 4. White spaces

1. Diaspora africaine francophone 25-50 ans : cuisine + Ramadan + non-culpabilité.
2. « Anti-Noom » : améliorer son corps sans maigrir ni médicament.
3. Transparence scientifique in-app : un niveau de preuve lisible plutôt qu'une caution PhD.
4. Coach qui explique ses non-décisions (journal de décisions).
5. Francophone sérieux : aucun équivalent FR de MacroFactor.

## 5. Recommandations

1. Positionnement : « le coach qui ne te pèse pas » ; attaquer la métrique poids, pas la précision calorique.
2. Prix : 69–79 €/an, 9,99 €/mois ; pas de lifetime.
3. Roadmap P0 : base ouest-africaine vérifiée + photo-logging via API tierce.
4. Roadmap P1 : rendre l'Evidence Layer visible dans l'UI et le marketing.
5. Go-to-market : niche diaspora FR / Afrique de l'Ouest avant Ramadan 2027 ; 50 cas « poids stable, taille −4 cm » comme preuve sociale.
